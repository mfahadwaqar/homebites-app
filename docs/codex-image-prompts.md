# Prompts for the 28 remaining dishes (for Codex / ChatGPT image generation)

These match the 22 images already made in Canva. Rules so the set looks like one family:

1. **Always generate 4:3 landscape** (for example 1600x1200). Use the same size for all.
2. **Attach a reference image with every prompt.** Download one finished Canva image from the same country folder (Thailand: Pad Thai; Pakistan: Chicken Biryani; Nepal: Sel Roti; India: Masala Dosa) and attach it, then add: *"Match the lighting, surface, camera angle, colour grading, depth of field and level of realism of the attached image exactly. Only the dish changes."* Bangladesh has no finished image yet. Generate Kacchi Biryani first, check it, then use it as the Bangladesh reference.
3. **One image per prompt, no text, no people, no hands, no watermark.** Square crops or logos are not wanted.
4. If a result looks like an illustration, add *"real DSLR photograph, 85mm lens, natural film grain"* and regenerate.
5. Save each file as the filename shown, in JPG, in one folder. Tell me when they are in.

Country style lines (already included in each prompt below):

- Pakistan: dark slate surface, black cast-iron karahi or brass serveware, warm directional side light from the left, deep moody shadows, 45-degree camera angle, garnish of sliced red onion rings, slit green chillies and lemon wedges, a dark linen cloth at the edge
- Bangladesh: warm wooden table, red checkered cotton cloth, terracotta clay or brass serveware, warm golden-hour light, slight overhead angle, green chillies as accents
- Nepal: rustic weathered wood, handwoven textile at the edge, brass and copper bowls, warm soft angled light, 45-degree camera angle, coriander or spring onion garnish
- India: light stone surface, steel thali / katori bowls or banana leaf, bright natural daylight, overhead camera, vivid colours, coriander, lemon wedge and sliced red onion on the side, a cream linen napkin and a brass or steel spoon at the edge
