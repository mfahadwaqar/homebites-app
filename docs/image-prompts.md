# Image prompts for the 50 dishes

Landscape 4:3, about 1600 px wide. For each dish, use the dish line plus the style line of its country, so images match inside a cuisine and differ between cuisines.

Save as `static/catalog/food/real/<CODE>-<slug>.jpg` (filenames are in `docs/dish-list.md`).
